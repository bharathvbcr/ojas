Decision rules, fixed before the first measurement (committed ahead of the results). No timing from `ojas-metal/examples/memory_bound_bench.rs` had been seen when this file was written.

Question. What do the memory-bound ops of the SpikeTrack frame actually cost on a quiet M5 Pro: the bias add (`broadcast_add_forward`) at the linear shapes of the GEMM study, and `permute` at the shapes `st-model` calls it with? The earlier numbers (the GEMM study's bias rows, the profile's permute row) came from contended runs, and a memory-bound op is the kind a contended run inflates (the neck conv's im2col and layout passes ran 2.4x slower in the contended run while the compute-bound GEMM next to them did not move).

Rule for what counts (from the coordinator's brief, verbatim in substance): a row counts only if its run's load is recorded and its A-vs-A' gap is within the spread.

Definitions, set here:
- Load. The 1-minute load average from `sysctl vm.loadavg`, printed by the example at the start and at the end of each run (`# load_start`, `# load_end`; the 5 and 15 minute values are printed beside it). A run is load-clean when both 1-minute values are at most 6.0.
- A and A'. Every arm runs twice in every round, once in each of two passes over the arms (the repeat is named with a trailing prime). Odd rounds walk the arms in reverse, so no arm is always first or last. The samples of a pass are the 25 timed rounds after 5 warm-ups.
- Gap and spread. gap = |median(A) - median(A')|. spread = the larger of the two p90 - p10 spreads of A and A'. A pair is `ok` when gap <= spread, else `NOISY`.
- A run is clean when it is load-clean and has no NOISY pair. The example prints the verdict (`clean` or `repeat`) as its last line. A run with verdict `repeat` is repeated, up to three attempts; every attempt stays in `bench-output.txt` with its load lines, and an attempt that is not clean contributes no row to any table. If no attempt is clean, the summary says so and quotes no number from this directory as measured.
- Bytes and GB/s. bytes = what the op must move: a read of its input and a write of its output (8 bytes per element for permute and for the bias add, plus the bias row for the bias add; a `fill` is the write alone). GB/s = bytes / median. The reference is the 170 GB/s the group_norm reached (`bench/results/2026-10-27-group-norm`); the same run also measures a `fill` of the bias add's output size, the write floor, so each bias row has a reference from its own machine state.
- Control. The f32 linear and the tagged bf16-lane linear run in the same run at each linear shape. They should repeat the GEMM study's quiet medians (f32 TFLOP/s within about 5% of `bench/results/2026-10-27-linear-gemm/bench-output.txt`'s 6.3 to 6.8 at the large shapes; the bf16 lane within about 10%). If a clean run's controls do not repeat, the run is read as contended and repeated all the same; the controls are not a gate on their own, they say which way a disagreement points.

Arms:
- Linear shapes: fc1, fc2, qkv, proj, the 9*576-row window proj, and the 256-wide ones of the GEMM study (`[5184,256]x[256,256]`, `[10400,256]x[256,256]`, `[5184,256]x[2048,256]`, `[5184,2048]x[256,2048]`). Arms: `bias add` on the `[m, n]` product, `fill` of `[m, n]`, `linear f32`, `linear bf16 lane`.
- Permute shapes: the call sites of `permute` in `SpikeTrack/crates/st-model` (listed with file and line in the example), at the shapes the 2026-10-27 profile lists for them: the head swaps `[0,2,1,3]` at D64 and D32, the window partition and merge `[0,1,3,2,4,5]`, the NHWC and NCHW moves of the neck and memory encoder, the token moves `[0,2,1]`, and the `[256, 82944]` and `[32, 82944]` transposes.

What would refute a reading: a row whose A and A' disagree beyond the spread (not counted); a clean run whose controls differ from the GEMM study's quiet medians by more than the tolerances above (the run is distrusted and the difference reported); bias-add GB/s near or above the `fill` GB/s of the same run (then the add is at the write floor and fusion cannot recover more than the extra read).
