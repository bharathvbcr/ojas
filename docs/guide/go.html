Go API reference

Package github.com/bharathvbcr/ojas/go. Every call takes a context.Context, and a nil context is an error. Calls run in-process on gusset's worker pool.

A model id names a nanolab GPT held on one device by the Rust engine. Go sends paths, token ids and options; weights never cross the boundary. The usual order is SetModelRoot, LoadModel (or NewModel), OpenTrainer, a loop of TrainStep, SaveCheckpoint, and GenerateIDs. Every path is relative to the model root. The worker pool defaults to 1; SetPoolSize changes it before the first call.

FunctionBehavior
SetModelRoot(ctx, dir)Directory that relative paths resolve under. Absolute paths and paths that leave the root are refused.
SetMemoryCeiling(ctx, bytes)Replaces the process-wide byte ceiling that every model's budget draws from (1 GiB by default). Refused for 0, and while any model is open: Free every id or Close first. A 124M training session needs several GiB, so raise it before loading.
SystemProfile(ctx, budget, measureBandwidth)Read-only. Returns the host profile and a plan for your budget: memory, core clusters, caches, whether memory is unified, pressure, and thread advice (a bandwidth measurement runs only when asked, takes about half a second and is not cancellable). A field the engine could not read is flagged unknown. It changes nothing: you pass what you choose to SetMemoryCeiling and LoadOptions.Threads. BudgetBytes counts logical bytes, so leave headroom on a Metal model.
LoadModel(ctx, path, LoadOptions)Reads a nanolab safetensors file (state_dict names, spec in __metadata__["ojas.spec"]), checks every tensor against the spec before keeping any, and uploads the weights to opts.Device. DeviceCPU, DeviceCPUParallel (Threads 1 to MaxCPUThreads = 256), DeviceMetal, DeviceWgpu. A device that cannot open is the load's error. BudgetBytes caps the model, its trainer and every call on it (0 means 1 GiB). Numerics is CPU only.
NewModel(ctx, ModelSpec, seed, opts)A fresh nanolab init: each parameter draws from its own counter RNG keyed by the seed and its name.
Inspect(ctx, path)Counts the tensors in a safetensors file from its header alone. No model id is created.
OpenTrainer(ctx, id, TrainConfig)Attaches a trainer at step 0 over a token bin (BinHeaderless or BinFineWeb). NanolabTrainConfig fills nanolab's defaults: Muon 0.025, AdamW 6e-4, clip 1.0, abort on a non-finite value. A model that already trains is refused.
TrainStep(ctx, id)One optimizer step over the next Accum sampled micro-batches. Returns StepResult{Loss, GradNorm, MatrixLR, AdamLR, Step, Tokens}; only the loss is read back. A step that fails before its optimizer commits nothing; one that fails inside it leaves the model ErrPoisoned.
TrainStepTokens(ctx, id, seq, x, y)The same step on caller micro-batches. The sampler's cursor does not move.
SaveCheckpoint(ctx, id, dir)Writes model.safetensors (loadable by LoadModel and torch), optim.safetensors and state.ojck. The directory is written beside dir and swapped in whole, so an error leaves an earlier checkpoint as it was.
Resume(ctx, dir, opts, cfg)A new model id with the saved trainer, continuing the run on opts.Device. cfg must equal the saved config field for field, tokenizer hash included; a mismatch creates nothing.
LoadTokenizer / Tokenize / DetokenizeA GPT-2 byte-level BPE from a Hugging Face vocab.json and merges.txt under the model root. Special tokens encode as plain text. Ids that do not form UTF-8 are an error.
GenerateIDs(ctx, id, prompt, SampleOptions)Continues the prompt with the model's current weights on its device. Temperature 0 is greedy; TopK, TopP, Seed, MaxNewTokens and Stop ids are options. The prompt and new ids must fit MaxSeq, else ErrCapacity before anything runs. Each forward reads back one logit row.
GenerateGreedy(ctx, id, prompt)GenerateIDs with temperature 0 and one new token.
Generate(ctx, id, logits)Argmax of caller logits on the host. It needs a live id but reads no model. A non-finite logit is an error.
Free(ctx, id)Drops a model id. An unknown id, including a second free, is an error. A call already running on the id finishes first.
Close(ctx)Joins the worker pool, drops every model and resets the engine, returning when the join ends or ctx does. If workers are still running after gusset's 30 s join budget, Close returns that error and no second pool is opened.

Matching errors with errors.Is

ojas.ErrCapacity a byte budget, the process memory ceiling, the 64-model table, or the model's context length

ojas.ErrNonFinite a NaN or infinity; the step committed nothing

ojas.ErrDeviceLost the device failed mid-session

ojas.ErrBusy another call holds this id (pool size above 1)

ojas.ErrPoisoned a trainer left partly updated; Resume from a checkpoint

gusset.ErrPanic the engine panicked during this call

gusset.ErrPoisoned a call after a panic, until Close

context.Canceled the call's context ended; a cancelled step commits nothing

The kind comes from the typed Rust error, not from matching message text, and counts only at the start of the engine's message, so a path that spells one never selects it. A cancel that lands after a step's last cancellable op does not stop it; the next result's Step says which happened.
